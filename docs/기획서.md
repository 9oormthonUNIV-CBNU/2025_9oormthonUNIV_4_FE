## 🧭 서비스 개요

### 📌 서비스명: 청년,기업간의 CONNECTION PlatForm (가제)

**실무 기반 청년-기업 프로젝트 매칭 플랫폼**

---

## 🗣️ 슬로건

**대학생용 → “실무의 첫걸음, Mustep”**

**기업용 → “당신의 아이디어,Mustep에서 현실로”**

---

## 🎯 서비스 목적

> “청년에게는 실무 경험을, 기업에게는 혁신적인 아이디어와 인재를”
> 

이 플랫폼은 실무 기반의 프로젝트를 통해 **청년과 기업을 연결**하는 매칭 시스템입니다.

청년은 실제 기업의 문제를 해결하며 실무 경험과 포트폴리오를 쌓고,

기업은 창의적이고 열정 있는 청년들로부터 **업무 지원 또는 신선한 아이디어**를 확보할 수 있습니다.

---

## 👥 주요 이해관계자별 가치

| 대상 | 얻게 되는 가치 |
| --- | --- |
| **청년(참가자)** | - 실제 기업 과제를 통한 실무 경험- 취업에 활용 가능한 포트폴리오- 팀 프로젝트를 통한 협업 역량 강화- 다양한 분야에 대한 탐색 및 경력 개발 |
| **기업(과제 제공자)** | - 자사의 실무/부수적 과제를 외부 청년에게 위임 가능- 청년들의 시각에서 도출되는 창의적 아이디어 확보- 우수 인재와의 초기 접점 형성- 자사 브랜드 인지도 향상 및 사회적 기여 |

## 🧩 활용 예시

- IT 스타트업 → *‘고객 리서치 자동화 툴’ 기획 아이디어 요청*
- 콘텐츠 기업 → *‘MZ세대를 위한 콘텐츠 제안’ 공모전 개설*
- 제조업체 → *‘환경 친화적 포장 개선안’ 실무 프로젝트 운영*

## 🔄 사용자 플로우 시각화

기업 과제 등록

↓ 

과제 상세 페이지

- 과제 개요, 필요 역량, 기간, 기업 정보 표시
- 팀 구성 방식 안내
- 최종 산출물 가이드라인 제시

↓

청년 유저: 과제 열람 및 참여 희망

↓

팀 구성 방식 선택

- 직접 팀 개설(팀장 역할)
- 기존 팀에 참가 신청

↓

  신청 전 팀장에게 1:1 문의 기능 

↓

  참가 신청 시 자기소개 + 포트폴리오 파일 첨부 

↓

  팀장 승인 → 팀 확정 

↓

과제 수행 단계

↓

팀장이 최종 산출물 제출 

↓

우리가 그 최종 산출물 취합 후 기업에 제출 

↓

기업 검토 및 피드백 

- 우수팀 선정 / 평가 진행 가능 (선택 사항, 추후 기능 확장 시 고려)
    
    ## 우수팀 평가 방식 – 제안 아이디어 (초안, 추후 기능 확장 시 고려)
    
    | 방식 | 설명 |
    | --- | --- |
    | **기업 평가 점수제** | 기업이 과제 종료 후 항목별 점수 (기획력, 창의성, 완성도 등) 선택 입력 |
    | **팀장 자가 평가** | 팀장이 간단한 회고/팀 퍼포먼스 평가 작성 |
    | **청년 커뮤니티 투표** | 우수팀 공고 후, 유저들이 투표로 ‘인기상’ 방식으로 참여 |
    | **성과 인증서 발급** | 특정 기준 넘으면 플랫폼에서 활동 인증서 자동 발급 |

## ✅ 사용자 유형 및 권한 정의

### 👤 1. 일반 청년 사용자 (참가자)

| 항목 | 내용 |
| --- | --- |
| 가입 시 정보 | 이름, 전공, 학교, 연락처, 관심 분야, 포트폴리오 업로드 |
| 주요 기능 | 과제 열람, 팀 지원 신청, 포트폴리오 제출, 팀장 문의, 팀 내 게시판 참여, 산출물 작성 참여 |
| 권한 요약 | 과제 참여 및 산출물 공동 작업 가능 (단, 팀장 승인 필요) |

---

### 🧑‍💼 2. 팀장 (청년 중 1인)

| 항목 | 내용 |
| --- | --- |
| 팀 구성 방식 | 직접 팀 개설 또는 기존 팀에서 리더로 임명 |
| 주요 기능 | 팀원 모집 공고 작성, 참가자 승인/거절, 팀 게시판 관리, 최종 산출물 제출 |
| 권한 요약 | 팀 내 리더 역할, 승인/관리 기능 보유 |

---

### 🏢 3. 기업 사용자 (과제 제공자) (추후 고려)

유저가 많아지기 전까지는 운영자가 기업에게 과제를 받아 게시판에 업로드

| 항목 | 내용 |
| --- | --- |
| 가입 시 정보 | 기업명, 담당자 정보, 기업 소개, 과제 목적 및 기대사항 |
| 주요 기능 | 과제 등록, 마감일 설정, 과제 열람 통계 확인, 산출물 열람 및 피드백, 우수팀 평가 |
| 권한 요약 | 과제 업로드 및 결과 수령, 후기/피드백 작성 가능 |

| **멘토/외부 전문가** | 청년 팀에 피드백 제공, 실무 코칭 역할 (추후 기능 확장 시 도입 고려) |

## 🔍 MVP란?

> “최소한의 기능으로 핵심 가치를 전달할 수 있는 제품”
> 

청년과 기업이 실무 프로젝트로 연결되는 경험을 **한 번의 매칭 + 제출**까지 시연 가능하면 성공!

---

## ✅ 🎯 우리의 MVP 핵심 목표

> 청년이 프로젝트를 찾아 팀을 만들고, 신청/승인/협업 후 산출물을 제출하는 일련의 흐름이 가능해야 한다
>

## ✅ 🚀 MVP 우선 기능 선정 (시연 필수)

| 기능 | 포함 여부 | 설명 |
| --- | --- | --- |
| 회원가입 / 로그인 |  | 역할 선택 포함 (청년) |
| 과제 등록 (운영자) |  | 기업에게 받은 과제를 운영자가 업로드 |
| 과제 리스트 / 상세 페이지 |  | 유저가 과제 탐색 가능 |
| 팀 만들기 / 팀 신청 |  | 팀 구성 프로세스 |
| 참가 신청 + 포트폴리오 첨부 |  | 자기소개 + 파일 제출 |
| 팀장 승인 / 거절 |  | 팀장 권한 기능 포함 |
| 팀 게시판 (간단한 글쓰기) |  | 초기 MVP에서는 생략 가능 (채팅/외부 공유로 대체 가능) |
| 산출물 제출 |  | 파일 업로드 및 마감 제출 기능 |
| 기업 평가 / 우수팀 선정 |  | 시연 시 생략 가능 (후속 기능) |

## 🧪 시연용 플로우 예시

> 💡 실제 발표/시연에서 보여주면 좋은 사용자 시나리오
> 
1. 운영자 계정으로 로그인 → 과제 등록
2. 청년 계정으로 로그인 → 과제 열람 후 팀 개설
3. 다른 청년이 해당 팀에 참가 신청 + 포트폴리오 제출
4. 팀장이 로그인 → 신청 승인
5. 팀원이 최종 산출물 제출
6. 기업이 결과 확인 (평가 생략 가능)

### 플로우

기업이 어떠한 과제를 주어줌 (직무별, 원하는 회사로 페이지 구성) ➡️ 팀원을 구성 ➡️ 게시판 구현 (과제에 대한 게시판 구현이 자신이 지원할 수 있는 섹션이나 자신이 만드는 섹션) ➡️ 유저가 참가 신청 (자신이 어떤 사람인지 확인 할 수 있어야함, 팀장이 승인을 할 수 있는 구조, 이 때 파일로 팀장에게 보낼 수도 있도록) ➡️ 팀 개설 ➡️ (이 사이는 못들었음…) ➡️ 최종 산출물을 취합해서 제출

### 주요 기능

- 회원가입, 로그인
- 과제 올리기
- 팀장이 팀 구성
- 팀원이 팀에 신청 (이 때, 포트폴리오나 관련 자료 제출할 수 있는 기능)
- 팀장이 팀원 구성
- 팀 개설
- 최종 산출물 제출 (파일 형식 구애받지 않고)
